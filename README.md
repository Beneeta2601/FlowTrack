# 🌸 FlowTrack – Menstrual Health Awareness Application

**PRJ No.: 518 | SDG 3 – Good Health and Well-being**

FlowTrack is a menstrual health awareness application that helps users track their menstrual cycles, record symptoms, predict upcoming periods, and access menstrual health and hygiene information.

## ✨ Features
- 🩸 Menstrual cycle tracking and period prediction
- 📅 Cycle history and phase information
- 📝 Symptom tracking
- 📊 Cycle analysis and insights
- 📚 Menstrual health and hygiene awareness

## 🛠️ Technologies Used
- **Frontend:** HTML, CSS, JavaScript
- **Backend:** Python/Java
- **Database:** SQL/MySQL
